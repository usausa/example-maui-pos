# 文書と規則

- `docs/` の Markdown は「。」で文を終え、2 スペースで改行する (表・見出し・コードは除く)。規則ファイルは 1 項目 1 行
- README には主要な画面と文書へのリンクだけを載せる(画面 ID や手順は書かない)
- `docs/` は人間向けの設計文書。現状 (何を・なぜ) を説明する
- AI 向け規則は `AGENTS.md` (進め方) と `.claude/rules/` (コードの書き方を領域別に) に置く。レビューの指摘は「どうあるべきか」の形で規則に追記し、該当する設計文書も直す
- 経緯と設計判断の履歴は `docs/decisions.md` にだけ書き、日付は書かない
- 設計判断は `docs/decisions.md` に記録し、フェーズを閉じる前に該当する設計文書を更新する
