# 全体

## 配置と名前

- SQL は Accessor の 2-way SQL と、スキーマ・初期データの SQL ファイルだけに書く (2-way SQL が取り込むサーバの `SqlHelper` の断片、後から増えた列を足す `SchemaHelper`、保存形式を確認するテストは除く)
- フォルダの直下には共通の部品だけを置き、1 つの機能に属するもの (機能のモデル、名称の辞書、絞り込みの状態、URL、帳票) は機能のサブフォルダか専用のフォルダに置く
- 例外として、型の種類で分けたフォルダ (`Models/Entity`、`Models/Views` など) に置くものと、領域の規則で置き場所が決まるもの (端末の `XxxBuilder`) は、1 つの機能に属するものでもフォルダの直下に置いてよい
- `XxxBuilder` の名前は、テキストや画像 (帳票、レシート) を組み立てるクラスだけに付け、データの変換や計算のクラスには付けない

## コードの書き方

- `ArgumentNullException.ThrowIfNull` は書かない (CA1062 は無効)
- 文字列の長さと入力の桁数は `Length` に定数を宣言して使い、数値を直接書かない (Request の `MaxLength`、フォームの `MaximumLength`、電卓の桁数)
- `Range` の境界と `MinLength(1)` は数値で書いてよい

## 拡張メソッド

- モデルと列挙型への拡張メソッドは、複数の条件を意味でまとめた判定 (`IsReturnable`) だけにし、単一の値との比較 (`status == TransactionStatus.Voided`) は拡張メソッドにしない
- 判定の拡張メソッドの静的クラスは、対象の型と同じファイルに置く
- フレームワークの型 (`NetworkAccess`) への判定は、それを使う型のファイルに置く
- 例外として、管理画面の表示用の加工 (書式の `ToXxxText`、列挙型の文言の `ToDisplayName`) は、サーバの `Application/ViewExtensions` に拡張メソッドとしてまとめる
- 例外として、列挙型を通信の文字列 (UPPER_SNAKE_CASE) にする `ToCode` は `ErrorCodeExtensions` にまとめる

## 業務のコードの追加

- 業務のコードを足したら、テストと文言を同時に足す (既定の分岐があるので、漏れてもビルドは通る)
- `ErrorCode` は `ErrorCodeTests` に足す
- `WarningCode` は `ErrorCodeTests` とサーバの `ApiRuleText` に足す (端末は警告を出さない)
- `RuleReason` は `ApiRuleText` と端末の `ViewHelper` に足す

## 画面の文言

- UI の文言は日本語だけにし、ローカライズのリソースは持たない
- 例外として、端末のテンプレートと同じにする共通の部品のメッセージ (前回の異常終了、ローカル DB を開けない) は英語のままにする
- 画面の文言 (端末・管理画面の表示、シート、トースト、入力の検証) は「。」が要らない短い句にし、文を重ねず、最後に「。」を付けない (帳票は対象外)
- 画面の構成やボタン・F キーの文言でわかる自明な案内 (端末の「QR を枠に合わせてください」「読み取ると登録します」、管理画面の「[保存] で反映します」のような手順や操作の説明、ヒントのバー) を出さない
- 説明やメッセージの文言は、異常や注意が要る状態 (読めない、見つからない、取得できない、権限がない、要確認)、画面からわからない業務ルール (役割でできること、登録できる件数、入力のルール)、操作の結果や事実 (追加した商品、「〜がありません」、取消できなくなる) を伝えるために使う
- 確認は「〜しますか？」にし、取り消しにくい影響を短い句で 1 つだけ添える (端末は次の行、管理画面は「？」の後に空白を置いて続ける)
- 値を見せる確認 (精算) は、値を 1 行ずつ質問の前に並べる (注意は先頭に置く)

## 絵文字とアイコン

- 画面で文言に添えるアイコン (見出し、一覧と表のセル、メニュー、メッセージ、端末のホームと設定のボタンの文言) は、明るい背景では色付きの絵文字にする
- 標準でテキスト表示になる文字 (ℹ、⚙、↩、▶、⏸、⚠、☁、🏷、🗑 など) を絵文字にするときは U+FE0F を付ける
- 濃い背景 (塗りつぶしのチップ、色付きのボタン、濃い色のバー) のアイコンは色付きの絵文字にせず、白い単色のアイコンにする (絵文字は背景に溶ける)
- 部品のアイコン (チップの `Icon`、ボタンの `ImageSource` と `StartIcon`、アイコンだけのボタン、管理画面のナビと KPI のカード) は Material Icons のグリフにする
- 帳票には絵文字を使わない (フォントに依存する)
