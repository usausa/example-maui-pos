# README

## 内容

- README は概要、主要な画面と帳票の画像と一言の説明、`docs/` の文書へのリンク、基にしたテンプレートへのリンクだけにする
- 画面 ID、手順、AI 向けの規則 (`AGENTS.md`、`.claude/`) は載せない
- 概要は数行にし、扱う機能の一覧は領域ごとの表にする
- 文書の表は、文書へのリンクと、主な章を添えた短い説明にする
- 基にしたテンプレートは最後の表に、リポジトリへのリンクと基にしたものを書く
- 詳細な説明は README に書かず、`docs/` の文書に置く
