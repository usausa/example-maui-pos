# 文章 (文書、規則、コメント)

## 書き方

- 文は短く明確にし、1 文に 1 つの内容を書く
- 前置き、同じことの言い換え、過剰な修飾と強調は書かない
- 括弧の補足は要るものだけにし、括弧を入れ子にしない
- 例の列挙は「、」、択一は「 / 」で区切る
- 文の中の引用 (「…」と) には「。」を入れない
- 経緯と日付は書かない (過去の形は git の履歴で追う)

## 用語

- 技術用語は一般的な表記 (カタカナ語、英語) で書き、和語に言い換えない (下の表)
- 業務の用語と画面の名前は、画面の文言 (端末と管理画面の表示) に合わせる (受注、前受金、シフト、精算、日次締め、アプリ版、ユーザー、オペレーターなど)
- カタカナ語は語末の長音を付けない形にそろえる (サーバ、ヘッダ、フォルダ、ブラウザ、パラメータ、インジケータ)。画面の文言は画面に合わせる
- 鍵 (公開鍵、秘密鍵)、専用端末、文言、添付プロパティ、回線 (Blazor の circuit) はそのまま使う
- 「DTO」という語は、コード、名前空間、文書に使わない
