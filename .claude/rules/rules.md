# 規則と手順 (AGENTS.md、.claude/)

- `AGENTS.md` と `paths` のない規則 (`common.md`) は常に読み込まれるので、どの作業でも要る規則だけを置く
- 領域の規則は `.claude/rules/` に置き、`paths` を規則が当たるファイルだけに絞る (入っていないファイルを触っても読み込まれず、余分に入れると読み込む量が増える)
- 同じ規則を複数の場所 (`AGENTS.md`、規則、skills、agents) に書かない
- ほかの規則ファイルを指すだけの行は書かない (当たるファイルを触れば `paths` で読み込まれる)
- 規則ファイルは 1 項目 1 行 1 話題にする (表とコード例は除く)。文書の「。」+ 2 スペースの改行は使わない
- 規則は「どうあるべきか」の形で書き、当て方を決める理由だけを短く添える
- 見出しの絵文字のような人向けの飾りは付けない
- 繰り返す手順 (検証、README の画像、エミュレータでの確認) は `.claude/skills/` にスクリプトと一緒に置き、規則は skills に書かない
- 繰り返す確認 (規則や文書とコードの照合、変更のレビュー) は `.claude/agents/` に、ファイルを書き換えないエージェント (Edit と Write を持たない。git を読む Bash は持ってよい) として置く
- skills と agents の `description` は、何をするかといつ使うかの 1〜2 文にする (常に読み込まれる)
- skills の手順は 1 行 1 操作を目安にし、注意はその手順の近くに書く
- 環境に固有の値 (デバイス、ポート、パス) は skills に書かず、スクリプトの引数か環境変数で受ける
